SECCION 5 - REFRESCAR DATOS DESDE CONTPAQ
==================================================

Servidor interno PowerShell:
1. Actualizar script local con la version nueva del repo:
	copiar scripts/contpaq_sync_agent.py a C:\contpaq-sync\contpaq_sync_agent.py

2. Configurar y ejecutar:
$envFile = "C:\contpaq-sync\.env"
$script = "C:\contpaq-sync\contpaq_sync_agent.py"

Configurar UNA sola vez para traer TODO desde 2025-01-01 hasta hoy:

(Get-Content $envFile) -replace '^CONTPAQ_START_DATE=.*$', 'CONTPAQ_START_DATE=2025-01-01' | Set-Content $envFile -Encoding ascii
if (-not (Select-String -Path $envFile -Pattern '^CONTPAQ_END_DATE=' -Quiet)) { Add-Content $envFile 'CONTPAQ_END_DATE=' }
if (-not (Select-String -Path $envFile -Pattern '^CONTPAQ_CHUNK_DAYS=' -Quiet)) { Add-Content $envFile 'CONTPAQ_CHUNK_DAYS=31' }
if (-not (Select-String -Path $envFile -Pattern '^CONTPAQ_REQUEST_TIMEOUT=' -Quiet)) { Add-Content $envFile 'CONTPAQ_REQUEST_TIMEOUT=300' }
(Get-Content $envFile) -replace '^CONTPAQ_END_DATE=.*$', 'CONTPAQ_END_DATE=' | Set-Content $envFile -Encoding ascii
(Get-Content $envFile) -replace '^CONTPAQ_CHUNK_DAYS=.*$', 'CONTPAQ_CHUNK_DAYS=31' | Set-Content $envFile -Encoding ascii
(Get-Content $envFile) -replace '^CONTPAQ_REQUEST_TIMEOUT=.*$', 'CONTPAQ_REQUEST_TIMEOUT=300' | Set-Content $envFile -Encoding ascii

Ejecutar historico completo:
py -3 $script

IMPORTANTE:
1. El script ahora manda ventanas automaticas de 31 dias.
2. Trae desde 2025-01-01 hasta la fecha actual.
3. Ya no dejar CONTPAQ_START_DATE en 2026-03-01 si ocupas todo el historico.

Si despues quieres volver a un rango operativo mas corto:
(Get-Content $envFile) -replace '^CONTPAQ_START_DATE=.*$', 'CONTPAQ_START_DATE=2026-03-01' | Set-Content $envFile -Encoding ascii
